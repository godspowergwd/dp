# Roadmap

## Phase 0 — Foundation
Documentation, repo structure, environment, database schema, authentication.

## Phase 1 — Core Private OS
Dashboard, product hub, research records and supplier records.

## Phase 2 — AI Gateway
Provider adapters, job queue, cost logging and research assistant.

## Phase 3 — Store Operations
Store connection, listing generation and controlled publishing.

## Phase 4 — Marketing Studio
Creative generation, asset library and approved publishing workflows.

## Phase 5 — Orders & Analytics
Order sync, fulfillment tracking and profitability.

## Phase 6 — Optimization
Automated suggestions, advanced analytics and optional agent workflows.
