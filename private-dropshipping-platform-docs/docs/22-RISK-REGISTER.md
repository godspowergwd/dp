# Risk Register

| Risk | Mitigation |
|---|---|
| Provider API changes | Adapter layer and version tracking |
| AI overspending | Budget limits and approval |
| Supplier outage | Multiple suppliers where practical |
| Bad product data | Source provenance and validation |
| Unauthorized API use | Official integrations and terms review |
| Credential exposure | Backend-only secrets and rotation |
| Free-tier service limits | Health checks and migration plan |
| Automation mistakes | Approval gates and audit logs |
