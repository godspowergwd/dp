# Feature Map

## Dashboard
KPIs, recent activity, pending approvals, AI spend and integration health.

## Research Lab
Source capture, research jobs, scoring, comparison and decision log.

## Product Hub
Catalog, variants, suppliers, costs, status and publishing history.

## AI Studio
Prompt templates, jobs, outputs, provider routing and asset library.

## Stores
Connected stores, products, publish jobs and synchronization history.

## Orders
Order list, fulfillment status, tracking and exceptions.

## Analytics
Profitability, product performance, marketing performance and operating costs.

## Settings
API credentials, model routing, thresholds, automation rules and backups.
